開始量測

  1. 沿用目前可正常運作的 ESP32 韌體、TFT 與 AD8232 接線，本版只更新網頁。
  2. 以 USB 連接 ESP32，關閉 Arduino 序列監控視窗。
  3. 選擇 115200，按「連接 ESP32」並選取序列埠。
  4. 電極重新接觸後需等待 3 秒穩定；暫停僅凍結顯示，接收持續。

資料與連線說明

格式：時間_ms,ADC,狀態\n；狀態 0 為電極脫落、1 為穩定中、2 為正常。取樣目標 250 Hz，實際速度可能受 TFT 繪圖影響。

示範資料由程式產生，與實際量測分開。CSV 匯出保留時間、原始 ADC、狀態與來源，另含濾波值、暖機、重設原因及濾波參數。獨立記錄不受即時緩衝淘汰影響。

若無法連線，請確認 USB 資料線、驅動與序列埠使用權限；Safari、Firefox 與多數行動瀏覽器不支援 Web Serial。
